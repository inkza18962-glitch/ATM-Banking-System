
# ATM Banking System

A simple ATM simulation built with Python.

## Features

- Deposit money
- Withdraw money
- Check current balance
- Handle invalid input
- Exit the program

## Technologies

- Python 3
- VS Code

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the Terminal.
4. Run the following command:

```bash
py atm_v3_test.py
```

5. Choose a menu option from 1 to 4.
